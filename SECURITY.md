# Security Policy

## Поддерживаемые версии

Проект находится в активной разработке; исправления безопасности вносятся в
актуальную ветку `main`.

## Как сообщить об уязвимости

Не открывайте публичный issue для уязвимостей. Воспользуйтесь приватным каналом
GitHub — [Security Advisories](https://github.com/webwayne88/agent-forge/security/advisories/new)
(Report a vulnerability) — с описанием:

- характер проблемы и потенциальное влияние;
- шаги воспроизведения (PoC, если есть);
- затронутые файлы/эндпоинты.

Ожидаемое время первичного ответа — в течение нескольких дней.

## Что в зоне внимания

- Утечки секретов: `GIGACHAT_AUTH_KEY` и прочие ключи берутся только из `.env`,
  не коммитятся (`.env` в `.gitignore`).
- Prompt injection: пользовательский ввод изолируется в промптах как данные.
- Сгенерированный код **не исполняется** на сервере (нет `eval`/`exec`/`subprocess`).
- SQL — только параметризованные запросы (asyncpg).

> Примечание: `verify_ssl_certs=False` для клиента GigaChat — намеренное
> требование интеграции со Sber GigaChat, а не недосмотр.
